## Provisional Response Targets

| Severity | Example | Target | Escalation |
| --- | --- | --- | --- |
| S0 | duplicate creation, cross-tenant access, execution without approval | immediate during support window | incident owner |
| S1 | blocked pilot session, failed execution with unclear state | same business day | technical owner |
| S2 | confusing flow, recoverable error | next review cycle | support owner |
| S3 | copy, minor visual issue | backlog review | pilot owner |

Targets are pilot operating goals, not contractual SLAs.

## Ticket Closure

Close a ticket only when:

- issue is classified;
- evidence is linked;
- owner is assigned;
- user receives resolution or workaround;
- finding register is updated if needed.

## Out Of Scope Requests

Do not promise new capabilities. Record the request and link it to evidence for the final pilot report.
