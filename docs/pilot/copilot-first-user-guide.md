# Portfolio Copilot Pilot User Guide

## What It Can Do

Portfolio Copilot can help create one strategic front from a conversation. It prepares an Action Plan for review before any change is made.

## What It Cannot Do In This Pilot

It cannot import files, create challenges, manage cohorts, evaluate readiness, make decisions, connect enterprise integrations or run a real AI provider beyond the configured deterministic adapter.

## How To Use It

1. Describe the strategic front you want to create.
2. Include name, objective, KPI, baseline, target, horizon, sponsor and priority when available.
3. Review the Action Plan.
4. Edit fields that are wrong or incomplete.
5. Approve only when the proposal is correct.
6. Execute to create the StrategicFront.
7. Open Portfolio Lead strategic fronts to verify the result.

## Action Plan

The Action Plan is the proposed change. It is not executed automatically.

Edit means changing the proposal. Approve means confirming the current version. Execute means applying the approved version through the Portfolio domain command.

## Recovery

If you refresh or leave, return to Portfolio Lead. The Copilot should recover the conversation, plan and execution result.

## Safety

Do not enter sensitive personal data, secrets, credentials or unauthorized confidential information.
