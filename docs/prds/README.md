# PRDs

Este directorio centraliza los PRDs del proyecto.

## Colecciones

- [Copilot First v1](./copilot-first-v1/README.md): paquete de PRDs para arquitectura Copilot-first, orquestacion transversal y modificaciones relacionadas.

## Uso recomendado

1. Leer primero el indice maestro de cada coleccion.
2. Identificar dependencias transversales antes de implementar.
3. Convertir cada PRD o grupo de PRDs acoplados en una rama o lote de commits verificable.
