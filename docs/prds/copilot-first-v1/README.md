# Starteria — Paquete modular de PRDs Copilot-first

## Propósito

Este paquete reestructura los PRDs para que el Copiloto sea la entrada y el orquestador, sin perder la especialización ni las variaciones de cada dominio.

## Archivos

1. `00_INDICE_MAESTRO_Y_ARQUITECTURA_DE_PRDS.md` — índice y ownership actualizado.
2. `00A_PRD_ARQUITECTURA_COPILOT_FIRST_Y_ORQUESTACION_TRANSVERSAL.md` — nuevo PRD transversal.
3. `01_PRD_ARQUITECTURA_PRODUCTO_WORKSPACES_Y_NAVEGACION.md` — actualizado con contrato Copilot.
4. `02_PRD_SMART_ENTRY_ROUTING_Y_REVISION_INICIAL.md` — reestructurado como motor conversacional reutilizable.
5. `03_PRD_DASHBOARD_ADAPTATIVO_STEPS_0_4.md` — actualizado con capacidades invocables.
6. `04_PRD_CONTEXT_VERSIONING_Y_CHANGE_IMPACT.md` — actualizado para cambios originados en conversación.
7. `05_PRD_SCOPE_GRANULARITY_Y_DECOMPOSITION_ENGINE.md` — actualizado para diagnóstico desde Copilot.
8. `06_PRD_PORTFOLIO_LEAD_IMPORTACION_Y_GOBERNANZA.md` — reestructurado con Portfolio Copilot como entrada principal.
9. `07_PRD_VALUE_INVESTMENT_READINESS_HANDOFF_Y_DECISION.md` — actualizado con comandos y proyección.
10. `08_PRD_AGENTE_IA_ESPECIALIZADO_Y_RUBRICAS.md` — reestructurado con Capability Registry y separación IA/ejecución.
11. `09_PRD_PILOTO_CALIDDA_Y_VALIDACION_TI.md` — actualizado para validar el journey Copilot-first.
12. `10_PRD_BACKLOG_COHORTES_CAPACIDAD_Y_PRIORIZACION.md` — nuevo PRD de operación por ciclos.
13. `CAMBIOS_Y_RUTA_DE_IMPLEMENTACION.md` — resumen de cambios, dependencias y primera secuencia vertical.

## Regla central

```text
Copiloto interpreta y propone
→ persona aprueba
→ motores de dominio ejecutan
→ dashboard registra y permite controlar
```
